# English from These Isles

**Inglês Britânico & Irlandês para Iniciantes** — ebook PDF didático (nível A1–A2).

## Arquivo principal

- [`Ingles_Britanico_Irlandes_para_Iniciantes.pdf`](./Ingles_Britanico_Irlandes_para_Iniciantes.pdf) — ebook completo (~29 páginas)

## Conteúdo

1. Como usar o ebook  
2. Alfabeto e pronúncia britânica  
3. Cumprimentos e primeiras conversas  
4. Números, dias, meses e horas  
5. Família e pessoas  
6. Vida quotidiana  
7. Comida e bebida (UK & Ireland)  
8. Gramática essencial  
9. Lugares e direções  
10. Inglês irlandês (Hiberno-English)  
11. Britânico × Americano  
12. Diálogos + exercícios com respostas  
13. Glossário A–Z  

Explicações em **português**; exemplos em **inglês britânico**, com notas **[IE]** para a Irlanda. Inclui ilustrações didáticas.

## Regenerar o PDF

```bash
pip install reportlab pillow
python3 src/build_ebook.py
```

Imagens em `images/`; script em `src/build_ebook.py`.
